# MEC Species Reference Image Credits

These images are used as **species reference photographs** for the Marine Education Center (MEC) website. They are intended to help visitors visually identify and learn about each species.

**Important:** These photographs are not photographs of the individual animals currently kept at MEC. The actual MEC animals are represented separately through the website's Chibi illustrations.
